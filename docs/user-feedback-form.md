# Ipon Google Form Template

## Form title

Ipon User Feedback — Level 5 round-up for the goal-based savings vault

## Questions

1. Name (short answer, required)
2. Email (short answer, required)
3. Wallet address (short answer, required; Stellar public key)
4. Role (multiple choice: Saver)
5. Product rating (linear scale 1–5)
6. What worked well? (paragraph)
7. What was confusing? (paragraph)
8. What should we improve next? (paragraph)
9. Would you use this product again? (yes/no)

## Response export

- Live Google Form URL: <IPON_GOOGLE_FORM_URL>
- Native Google Sheet response export: <IPON_GOOGLE_SHEET_URL>
- Feedback log with wallet mapping: [user-feedback-log.md](user-feedback-log.md)
